# 12. 附錄：現行實作對照

> 前 11 章是技術中立的規格。這一章是**現行實作**（Python 3.14 + PyMuPDF + RapidOCR + python-pptx）的對照表——想沿用同一條路的人可以直接對照；想換技術棧的人請把它當成「這些坑長什麼樣」的參考。
>
> ⚠️ **這一章是隔離區。** 規格正文不出現模組檔名與私有函式名，全部集中在這裡。新增一條規則時：**規則本身**寫進對應章節，**指路**寫進這裡。這個安排讓正文換一種語言重寫時可以整章拿走，而這一章是唯一要重寫的。
>
> ⚠️ **常數的正典永遠是程式碼**，這裡與 `CLAUDE.md` 都是整理版（`tests/test_docs.py` 釘著值要一致）。

## 12.1 技術棧

| 層 | 選用 | 為什麼 |
| --- | --- | --- |
| 語言／環境 | Python 3.14，`uv` 管理 | |
| PDF 渲染 | PyMuPDF @200dpi | 同一張渲染圖**同時**供 OCR、樣式估計與投影片背景使用，全程不重繪 |
| OCR | RapidOCR，PP-OCRv5 + **server** 辨識模型 | 繁中準確度遠勝預設的 v4 mobile；`--fast` 可切回 |
| 推論後端 | ONNX Runtime **DirectML** | 見 §9；本機裝的是 `onnxruntime-directml`，取代 CPU 版 |
| PPTX 輸出 | python-pptx（部分直接寫 XML） | 東亞字型必須自己注入 `<a:ea>`，見 §8 |
| 簡繁 | OpenCC，**s2tw**（不是 s2t） | s2t 會把「吃」改寫成「喫」，見 §3 |
| 字寬量測 | Pillow 讀 `msyh.ttc`／`arial.ttf`／`ARIALN.TTF` | 換字型不會跟著換度量衡，見 §4 |

## 12.2 模組地圖

| 檔案 | 職責 | 規格章節 |
| --- | --- | --- |
| `pdf2ppt.py` | CLI 薄殼 | — |
| `pdf2ppt_gui_2.py` | Tkinter 圖形介面。⚠️ **選項清單是手抄 argparse 的** | §9 |

| `render.py` | PyMuPDF @200dpi 渲染 | §2.1 |
| `ocr.py` | RapidOCR 呼叫（含方向分類器的形狀閘門）+ 十四條文字修正 | §3 |
| `style.py` | 字級、顏色、粗體、幾何的逐行估計；寬度量測；字級階梯 | §4、§5、§6 |
| `blocks.py` | 十六個調和／丟棄 pass | §4、§5、§6、§7 |

| `models.py` | `Line`／`Style`／`TextBlock`／對齊常數 | §2 |

依賴方向：`cli` → 管線 → `models`，不回頭。兩條刻意的邊：

- **`blocks` import `style`**（`_measure_em`／`snap_font_size`／`text_width_em`）：調和 pass 要重算「這個字級放不放得下」，而寬度量測只能有一份。反向不成立。
- **`builder` 不 import `style`**：它只吃 `Style` 的欄位。⚠️ 這條邊正是 §2.3 說「裁切必須寫 `cover_band_px` 而不是改字墨界」的原因。

## 12.11 框架地雷

換技術棧的人不會踩到同一顆，但會踩到自己那一套的等價物——這裡記的是「現行函式庫在哪裡違反直覺」。

- ⚠️ **`numpy` 的 `np.roll` 會繞回對邊。** 環帶膨脹一路走到 18px 時，字墨環會被抹到裁切的另一側，底色因此取到完全無關的地方。現行實作改用不繞回的 `_grow`；被它取代的 `_dilate` 於 2026-08-23 移除（零呼叫者卻留了半天，是「改壞了重試要清殘骸」那條規則的實例）。**任何影像鄰域運算都要先問「邊界怎麼辦」。**
- ⚠️ **`RapidOCR` 的 `use_det`／`use_cls`／`use_rec` 跨呼叫殘留。** 每次引擎呼叫都必須三個旗標全部顯式傳入，否則上一次的設定會漏到這一次（見 §3 的行尾標點復原）。
- ⚠️ **`python-pptx` 的 `font.name` 只設 `<a:latin>`。** 東亞字型要自己注入 `<a:ea>`，否則中文會悄悄回落到佈景主題字型（見 §8）。
- ⚠️ **PowerPoint 對負寬度零容忍。** 形狀寬度算成負值時，PowerPoint 直接判檔案損毀、要求修復，該塊文字消失——所以裁切的邊界一定要鉗回框內（見 §6.3）。

---

⚠️ **§11 是唯一還帶著實作名詞的正文章節**：它記的是「查證過但決定不動的結構性風險」與「量過而否決的路」，兩者都以現行程式碼的某個位置為主詞（某個函式對某個輸入的反應不是單調的），抽掉名字就沒有意義了。那一章本來就是實作綁定的隔離區，與本章同性質。
